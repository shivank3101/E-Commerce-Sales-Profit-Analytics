🛒 E-Commerce Sales & Profit Analytics

An end-to-end data analytics project that analyzes e-commerce sales, profit, customers, products, and regional performance using Python, SQL, and Power BI.

The project transforms raw sales data into meaningful business insights through data cleaning, exploratory analysis, SQL queries, and an interactive Power BI dashboard.

---

📊 Project Overview

This project focuses on understanding e-commerce business performance and answering important questions such as:

- How are sales and profit changing over time?
- Which products and categories generate the most revenue?
- Which regions and cities perform best?
- Which customer segments contribute the most orders?
- What are the most profitable products?
- Which payment methods are most commonly used?
- What factors affect overall profitability?

---

🎯 Project Objectives

- Analyze overall sales and profit performance
- Identify top-performing products and categories
- Analyze customer and regional performance
- Track monthly sales and profit trends
- Calculate important business KPIs
- Use SQL for business-oriented data analysis
- Perform data analysis using Python and Pandas
- Build an interactive Power BI dashboard
- Present actionable insights through data visualization
